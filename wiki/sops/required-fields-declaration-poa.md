## Required fields

Both a statutory declaration (υπεύθυνη δήλωση) and a power of attorney (εξουσιοδότηση) require the same core identity data set from the client before drafting can begin.

The client's full name is required, exactly as it appears on the ID document.

Both parents' full names are required: father's full name and mother's full name.

The ID card or passport number is required.

The issuing authority of the ID card or passport is required.

Nationality is required.

The date of issue of the ID card or passport is required.

The expiry date of the ID card or passport is required.

The home address is required.

## Notes
This is the minimum field set for drafting. It does not cover which instrument, υπεύθυνη δήλωση or εξουσιοδότηση, is correct for a given filing; that routing sits in the existing sops page on the εξουσιοδότηση workflow.
